# Seq2Seq Lab

This repository contains Sequence-to-Sequence (Seq2Seq) based experiments implemented as part of a lab/workshop.

## Experiments
1. Machine Translation
2. Text Summarization
3. Speech Recognition

## Folder Structure
- `Experiment-01-Machine-Translation/` – Seq2Seq model for translation
- `Experiment-02-Summarization/` – Text summarization experiment
- `Experiment-03-Speech-Recognition/` – Speech-to-text experiment
- `datasets/` – Input datasets
- `results/` – Outputs and evaluation results
